Pareto Anywhere

The open source middleware to identify, sense and locate "things" using common data standards.

Pareto Anywhere translates everything into standard data you can readily use and apply to anything.

Identify, sense and locate everything.

Pareto Anywhere provides a standard stream of real-time data, regardless of the underlying devices & technologies.

Middleware?

Why?

Although wireless protocols like Bluetooth Low Energy, RAIN RFID, and the EnOcean Wireless Standard strictly specify how data is transmitted over-the-air…

  • …every gateway/reader/AP vendor provides the decoded data in their own proprietary format 🤷
  • …few standards exist (or are observed) for sensor data payloads 🤷
  • …every RTLS vendor provides location data in their own proprietary format 🤷
Pareto Anywhere translates all these formats into common data standards for true vendor-and-technology-agnostic interoperability.

Messy data goes in…

Pareto Anywhere includes modular connectors (/barnowl-x) to gateways, readers & APs so that you can collect data from existing infrastructure whenever possible.

Pareto Anywhere includes modular libraries (/advlib-x) to interpret tag, beacon & wireless sensor payloads, including those of ambient devices already in your space.

Ambient Devices Infrastructure

…usable data comes out

Pareto Anywhere maintains a real-time graph of devices, their data, spatial relations and associations, which we call Hyperlocal Context:

  • Identifiers are represented in a common format (id/type)
  • Sensor data is represented using common properties with standard units
  • Location data is represented as standard GeoJSON

Real-time data is relayed/stored as open standard raddec, dynamb & spatem JSON.
